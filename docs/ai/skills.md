## Curation

Imported or adapted from the reviewed local 2nd-brain snapshots recorded in [sources.json](../../skills/sources.json). This records source and installed hashes, known upstream revisions, licenses, and adaptations. It is not a claim that every copied upstream payload is current. SwiftUI Expert's original revision was unknown; its official MIT license is included and that uncertainty is retained.

The November 5 additions include Impeccable's Apache-2.0 references and notices, UI/UX Pro Max's MIT search scripts/data, and native adapters for Harden and Clarify that reuse those references. Xcode Previews is a repository-maintained workflow adaptation: the original script revision/license was not established, and its project-injection scripts are not copied. No Impeccable engine, downloader, browser automation, automatic hook, or bundled agent configuration is installed. Read the copied references through their local adapters; upstream engine/setup instructions do not apply here.

Use a focused skill for a focused request. Do not run overlapping Impeccable, Harden, and Clarify passes automatically for every UI edit. For material and toolbar work, retain [the verified Liquid Glass guide](../LIQUID_GLASS.md).

The architecture, privacy, build-security, and device-verification notes were adapted into focused `ai-rules/` instead of copying personal workflows. Personal task systems, account details, machine setup, automatic skill launchers, Android-only libraries, and broad cosmetic command bundles were omitted.

To refresh: stage sources separately, review the diff and license, preserve the adapters and local conventions, update provenance hashes, validate references, and test the relevant workflow. Do not blindly overwrite this directory with a newer upstream package. New reference claims still need verification against the project's current targets and official documentation.
