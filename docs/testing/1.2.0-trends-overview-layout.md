# Trends Overview aspect ratio

Overview metric cards use a 1:1 aspect ratio owned by the material background shape. Text is overlaid inside that shape, so wrapping and Dynamic Type do not change the card dimensions. Existing two-column regular text and single-column accessibility layouts remain in use. Content padding stays at 12 points to leave space for larger text; labels and values wrap without a font-size cap.

Verification: all 46 Trends view-model tests passed; Debug and Release builds succeeded. On the synthetic-data iPhone SE simulator, iOS 26.5, inspected standard, extra-small, and accessibility XXXL text sizes. The first card measured 166 × 166 points at standard size and 343 × 343 points at accessibility XXXL; its long label and value fit. Screenshots remain outside Git. No metric calculations, stored settings, dose records or history were changed.
