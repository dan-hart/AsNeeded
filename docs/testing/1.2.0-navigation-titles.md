# Main-tab navigation titles

October 28, 2026. Medication, History and Trends now explicitly request the same native large-title display mode used by Settings. The existing font-aware navigation helper remains in use; detail and sheet titles retain their existing presentation.

History required a layout correction beyond changing the display mode: its filter/date controls previously preceded the list in a vertical stack, preventing the navigation bar from following list scrolling. Those unchanged controls now occupy a top safe-area inset. Their background stays within the inset so it cannot obscure the expanded title. Filtering, date selection, dose logging and data ownership are unchanged.

Verification on an isolated small iPhone simulator, iOS 26.5, 375 × 667 points, synthetic medication/history data:

- Debug build succeeded: `/tmp/asneeded-navigation-titles-build3.log`.
- Medication and Trends show large titles at the top. Trends collapses on scroll; Medication collapse was also verified at accessibility-medium text size, where its three records require scrolling. Standard text retains all three compact medication rows.
- History's corrected list collapses the title from a large leading heading to a small centered heading while the filter/date controls remain visible. Expanded and collapsed screenshots were inspected after correcting the inset background.
- Captures and accessibility outlines remain outside Git: `/tmp/asneeded-history-title3-{large,small}.png`, `/tmp/asneeded-trends-title-{large,small}.png`, `/tmp/asneeded-medication-title-ax-{large,small}.png`.
- The simulator text size was restored to its ordinary setting. No medication records were changed for this check.

No persistence, notification, calculation or dependency changes are included. Verification uses compilation and rendered interactions rather than tests that only mirror three title modifiers.


## Native History controls follow-up

The earlier top safe-area inset has been removed. Medication filtering and Jump to Date now share the native trailing navigation toolbar, with standard filter and calendar icons and app accent tint. A native navigation subtitle shows All medications or the selected medication. The menu uses the existing selection binding through a Picker so iOS supplies selection checkmarks. The existing graphical date sheet and logging actions are retained.

Verification: 24 History view-model tests passed; Debug and Release builds succeeded. On the synthetic-data SE simulator (iOS 26.5), selecting Headache relief changed the visible history and subtitle; the calendar action opened its date sheet and cancellation returned to History; scrolling collapsed the History heading from 43 to 22 points. Standard light and accessibility-medium dark appearances were inspected. No history records or persistence code were changed.
