# Temporary Demo Mode

Explicitly requested for 1.2.0 on October 28, 2026.

- The toggle is last in Data & Privacy, after Privacy Choices.
- State lives only in memory and starts disabled on process launch. There is no
  preference key, model change, migration, or alteration to saved medication names.
- Medication names use SwiftUI placeholder redaction. Presentation-only anonymous
  labels also protect native menus, navigation titles, and accessibility strings.
- Name editing and medication search use secure fields in Demo Mode; bindings,
  selection IDs, recording actions, and stored names retain their original values.
- Yellow warning buttons appear inline near the top of each tab's scrolling content.
  They scroll with the content and request confirmation before turning Demo Mode off. Empty states
  retain a reachable warning. Medication details and Data & Privacy also show it inline.
- Screen copy explains the session reset and that exports, notifications, widgets,
  and saved records are unchanged. Demo Mode does not hide all clinical data or notes.
- Turning it off through either a banner or the toggle presents a native alert.
  Names remain hidden until Show Medication Names is explicitly confirmed.
- Temporary dose confirmations no longer contain support banners. Their four-second
  dismissal and event-specific Undo remain intact.
