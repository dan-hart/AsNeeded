# 1.2.0 shared logging controls

## Behavior

- Medication-row Log controls have 16-point horizontal and 12-point vertical padding, with a minimum 60-point target.
- Filled action labels and the dose-form medication icon use white normally and black with Increase Contrast. Per the maintainer’s exact-color preference, displayed fills and saved medication colors are unchanged; no darkening or lightening is applied. Native unfilled toolbar controls retain their accent treatment. Color-choice swatches retain the exact preview color.
- Medication, History and Trends share the same floating Log Dose component. Settings has none. Tap opens the medication chooser; hold logs the default dose for the last recorded active medication. Its color identifies that target. Accessible quick-log actions are exposed alongside the gesture.
- A new device-local ordered event-ID preference preserves recording order for backdated saves and after Undo. It commits and rolls back with the dose/stock transaction, skips retries, and is excluded from backup settings. Legacy installs fall back to valid dated history.
- Native TipKit provides dismissible, limited-frequency guidance for logging, History filtering and Trends ranges. Existing quick-log discovery preferences are honored. Tips contain no medication names or history.

## Verification

- Full serial simulator suite: 866 tests, 81 suites, zero failures. Includes new palette tests and recording-order, restart, rollback, interrupted-commit recovery, retry and unavailable-target cases.
- Backdated three-save Undo regression failed before the recording-order repair and passed afterward.
- Visual and interaction checks on the existing synthetic-data iPhone SE (3rd generation), iOS 26.5, Debug 1.2.0 (317): padded medication buttons with all three example rows visible at standard text; native logging tip display/dismiss; History floater tap to chooser and medication form; hold to log and Undo; shared Trends floater; light/dark and Increase Contrast; largest accessibility text floater; Settings exclusion.
- Dose-form icon and primary button were inspected in ordinary and increased contrast. Stepper backgrounds scale with Dynamic Type.
- Physical iPhone SE, iOS 26.7.2: all seven isolated recording-recency persistence tests passed, including restart and interrupted-commit recovery. The Debug test build was installed in place; fixtures use separate temporary stores and UserDefaults suites.
- No TestFlight upload, hardware VoiceOver traversal or haptic assessment was performed for this change. This receipt is not an accessibility certification.
