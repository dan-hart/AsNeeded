# Medication detail controls and timing

- Log Dose and Edit Medication share the same full-width button style and the medication's exact custom color (app accent when unset). Existing white/black Increase Contrast label behavior is retained.
- The appearance icon has 16-point padding and a minimum 64-point area; action icons have additional padding and spacing.
- Dose Timing is omitted when neither an interval nor a rolling daily maximum is saved. Configured timing follows Supply & Refills, when present. Populated legacy profile values use the same fallback as the existing guidance service. Unset limit fields do not add empty-information rows.
- The existing Delete Medication menu item uses red text and a red monochrome trash symbol, retaining its destructive role and confirmation. No deletion behavior changed.

Verification: 31 detail/status tests passed; final Debug and Release builds succeeded. On the synthetic-data iPhone SE simulator, iOS 26.5, checked custom red and purple button colors, icon spacing, the new Edit action and cancellation, hidden timing for an unconfigured medication, populated timing below supply, and both red parts of the destructive menu item. Standard and accessibility-medium layouts were inspected. No dose, medication or history records were changed during these UI checks; no destructive action was confirmed. Screenshots remain outside the repository.
