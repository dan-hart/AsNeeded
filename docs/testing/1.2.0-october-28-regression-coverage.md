## Review fixes

All four inline findings accepted and fixed:

- Hosted scanner redaction now suppresses unparsed lines rather than printing matching credential content. Synthetic colon/newline/unparsed path regressions reproduce the original leak and pass after the fix. Credential matching remains enabled.
- Widget commits use the same model-aware guidance as the app, inside the existing persistence transaction. First-dose maximums, absent quantity/unit, migrated intervals, rolling maximums, unknown units, archive/delete and exact boundaries are covered. Logging eligibility is separate from known timing clearance so no-limit/first-dose widget actions remain usable.
- About now reports the ANModelKit revision and RevenueCat version actually shipped. A consistency check compares every dependency entry with the complete Package.resolved file.
- Widget commits explicitly reconcile opted-in availability alerts and delivered reminders. Reconciliation reads fresh storage, retries overlapping edits/doses, removes deleted records' alerts, and fails closed on unreadable state or repeated changes. Notification failure never reports an already-committed dose as failed. Extension alerts stay generic because the main app's container-only name-privacy preference is unavailable there.

Independent review found and verified fixes for first-dose maximum bypass, hidden no-history logging actions, and replacement-notification races. Focused widget suites passed before the complete final run. Physical widget delivery while the app is terminated still needs a device release check; injected notification clients verify the local logic without requesting real notification permissions.
