# 1.2.0 (315) Medication-tab Log Dose entry point

October 28, 2026. Explicit maintainer request for a large Medication-tab Log Dose action and an inventory of earlier local work. See [local worktree inventory](local-worktree-inventory-2026-10-28.md) for provenance and separate candidates.

## Implementation

Adapted the picker-to-existing-dose-form handoff from commit `8fab48f` on the other development line. The new large accent action reserves its own bottom safe-area inset above the tab bar. With one active medication, it opens that medication's current Log Dose form directly; with multiple active medications, it opens a full-height native searchable chooser. Current list order is preserved, archived medications are excluded, and the chosen ID is revalidated after the chooser dismisses. Selection and search match display/clinical names. Cancelling the chooser records nothing.

The picker dismisses before opening the existing dose sheet, retaining the current session/draft behavior. Search lives in the parent so child sheet rehosting does not inherently discard it. Existing row controls, custom Log colors, compact rows, five time presets, guidance colors and atomic persistence remain in place. The large action is hidden during edit mode and when no active medications are available. No new persistence key/dependency, direct quick-log action in the chooser, hint system, History feature, Mac/iCloud change or design-system migration was imported.
