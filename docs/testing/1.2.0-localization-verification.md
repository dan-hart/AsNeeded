# 1.2.0 localization verification

The app, notifications, widgets and Watch use all 42 existing app localizations. User-entered names, stored unit identifiers, quantities, settings keys, schemas and wire identifiers remain unchanged. Translations and the additional critical-wording review were machine-assisted; they are not native-speaker certification.

## Resource and behavior checks

- Native compilation includes all 1,728 translatable Localizable keys, 11 translatable InfoPlist keys and 25 indexed Siri phrase variants in every language. The English app brand remains unchanged.
- Compiled app, widget and Watch resources were independently checked for missing keys and unintended English placeholders. Placeholder types, native plural forms, protected tokens, locale-specific numeric input and exact-source fingerprints were validated separately.
- Representative native Spanish, German with extra-large text, Japanese, Arabic, Hebrew and Persian screens were inspected. These checks do not constitute physical-device delivery or every-language VoiceOver certification.
- The full regression suite passed 984 tests, including 1,157 executions with parameterized cases, with no failures or skips. The native test phase took about 33 seconds on the verification host, excluding build and launch time.
- Simulator test-host preflight failures contained no failed assertions. A fully booted isolated simulator and native serial Xcode test-host launch completed the entire suite successfully; no assertions were removed or skipped.

## Native close-button follow-up: build 323

Native screen capture exposed a UIKit-owned accessibility fallback: a standard close button announced English `Close` in Persian even though the app's Persian catalog contained `بستن`. The original native API behavior was reproduced before verifying the correction.

Nine native close buttons now explicitly use the app's localized accessibility label. Five existing, more specific close labels were retained. Roles, actions, icons, toolbar placement, tint, layout and medication behavior are unchanged. The existing all-language resource test now also checks `Close` in all three shipping bundles.

A disposable native SwiftUI toolbar probe reproduced the Persian mismatch, then verified the explicit label against the actual compiled app resources in all 42 languages. This is native API evidence; it does not replace manual VoiceOver testing of every app view. No UI or snapshot test framework was added to the repository.

Build 323 retains 1.2.0 and uses the next build number after the already processed 322. Source must be committed and pushed before archive/upload; processing and signing evidence belong in the release receipt. Public App Review submission and release are separate actions.
