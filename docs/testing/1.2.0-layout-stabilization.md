# 1.2.0 layout stabilization — October 28, 2026

## Reproduction and corrections

The supplied Log Dose screenshot shows Before/After/Effect cards centered at their intrinsic text widths. Reproduced in the isolated iPhone 17 simulator on iOS 26.5 with synthetic records. `LazyVGrid` proposes a full cell width, but the card's VStack/background did not expand to it.

- All rating-card backgrounds and the Side Effects card fill their grid cell, with matching leading alignment. The menu uses the app accent. Existing selections and logging behavior are unchanged.
- Reason accepts multiline input and has a shorter example. Existing entered text is preserved; no persisted model change.
- At AX5, the scaled 120-point minimum amount width caused the whole sheet and sticky button to extend past the screen edges. Keep that minimum unscaled while allowing the actual text to scale. The existing vertical stepper layout remains. The sticky action permits multiline text.
- Dose Check, How It Went and Note headers stack their badges below the title at accessibility sizes, avoiding narrow title columns.
- Common Medications uses one column at accessibility sizes.
- Color swatches retain a comfortable 70-point target and use available-width adaptive columns; decorative circles no longer grow with body-text scale into overlapping fixed columns.
- The default-color row keeps decorative-circle/horizontal spacing stable as text grows, and permits its labels to wrap. This fixes the reproduced one-letter-per-line Default label at AX5.
- The shared appearance sheet keeps preview/CTA padding at 16 points, omits the redundant Color indicator at accessibility sizes, and uses the concise Save action with wrapping support. This fixes a reproduced split medication name and truncated Save label. The color section title is simply Color.
- The symbol grid sizes accessibility columns using the scaled symbol-cell width, and permits symbol captions and its heading to wrap at those sizes. Its search prompt is shortened to Search. Standard-size column behavior remains unchanged.

## Wider source review

Searched shipping SwiftUI sources for fixed/minimum widths, intrinsic-size backgrounds, single-line critical text and grid constraints. Reviewed the related medication list/detail/edit cards, reminder type/weekday/date cards, Trends metrics/calendar, Support cards, settings layouts and shared components. Existing full-width frames/Spacers, vertical accessibility layouts, and the intentionally horizontally scrollable calendar are retained. Fixed icon dimensions are not expanded into full-width controls. This is a focused layout correction, not a redesign or new feature.
