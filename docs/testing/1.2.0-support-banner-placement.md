# Support banner placement verification

Medication and History show the support suggestion after their records, inside
the scrolling content. Medication hides it during editing. Trends retains its
existing footer. Logging a dose now shows its dose confirmation without an
automatic support promotion.

All support presentations share the app-blue card, a top-right Close control,
a full-width Close button below the card, and Don't Show Again. Close dismisses
the current presentation; Don't Show Again uses the existing global
`hideSupportBanners` preference. No storage schema or preference key changed.

## Verification

- Red/green regression coverage confirms manual dose logging shows its dose
  confirmation with the global banner preference both enabled and disabled.
- 43 focused tests passed across Medication list, Undo races, and History.
- Full suite: 866 tests across 81 suites passed.
- Release iOS build succeeded; diff whitespace checks passed.
- Independent code review found no actionable issues.
- iPhone SE simulator: visually checked Medication and History footer placement,
  app-blue styling, and reachable controls. At accessibility-medium text size,
  all footer controls scroll clear of the floating Log Dose action.
- Verified top-right Close and lower Close dismiss their presentation; a restart
  restores temporary dismissals. Support opens the existing Support screen.
- Verified Don't Show Again on Medication also hides the History banner. Restored
  the simulator's original global opt-out and normal text size afterward.

Testing used synthetic simulator records and did not log, delete, or modify doses.
Physical-device installation confirms launch, not a full device accessibility audit.
