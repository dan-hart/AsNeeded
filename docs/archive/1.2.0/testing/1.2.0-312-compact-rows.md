# 1.2.0 (312) compact medication rows

October 28, 2026. Stabilization correction for medication text squeezed between a large icon and Log control, causing excessive vertical wrapping on small iPhones.

## Change

Standard-size rows have a compact header containing a 40-point identity icon (minimum 44-point control area), expanding medication name/clinical name and a 52-point Log control. Stock, progress and last/next dose timing use the full card width below. Standard card padding is 12 points; list spacing is 5 points above/below. Medication names are not truncated. Accessibility text sizes retain the existing vertical layout with full-width actions; three-row fit is not imposed at accessibility sizes.

The previous row badges/limits headlines remain removed. Log Dose also hides the no-configured-limits guidance section when the assessment is clear. Existing configured limits and actual non-clear assessments (such as duplicate-dose warnings) still show guidance. Saved records, units, limits, logging, Undo, notifications and persistence behavior are unchanged.
